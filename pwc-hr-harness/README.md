# pwc-hr-harness

HR 전략적 인력계획(SWP) 하네스 플러그인. 「AI Powered Workforce Planning」 과정(3일)이 쓰는 **기본 인력계획 에이전트 팀**과, 그 팀을 **자사 버전으로 키우는 HR 특화 메타하네스 스킬**을 담았다. 판단 기준(법전)은 Day 1 교안 「방법론」 · 「Skill」 장이고, 모든 결과는 **HTML 뷰어**(`hr-viewer.html`)로 본다. revfactory/harness 의 메타하네스 방식(감사 → 설계 → 생성 → 오케스트레이션 → 검증 → 진화)을 HR 도메인에 맞춰 차용했다.

## 설치

Claude Desktop Code 탭의 **terminal 패널**에서 (마켓플레이스는 둘 가운데 하나):

```
claude plugin marketplace add ./pwc-hr-harness                # 이 폴더가 있는 곳에서 (로컬 경로 · 교육장 · hr-agent 안 사본도 같음)
claude plugin install pwc-hr-harness@pwc-hr-marketplace
```
- Desktop 채팅창의 `/plugin …` 명령은 동작하지 않는다. 설치 명령은 terminal 패널에서 한다
- 명령 이름: 플러그인 명령의 정식 이름은 `/pwc-hr-harness:hr-init` · `/pwc-hr-harness:hr-run` · `/pwc-hr-harness:hr-view` · `/pwc-hr-harness:hr-customize` 다. 짧은 이름 (`/hr-run` 등)이 「명령 없음」이거나 다른 명령과 겹치면 정식 이름으로 친다. 무인 실행 (`claude -p`)에서는 정식 이름을 쓰거나, 명령 없이 문장 (예: 「E-co 인력계획 이어서 해 줘」)으로 보낸다 (메타 스킬 · `wfp-lead` 가 문장으로 같은 순서를 따름)
- 필요: Claude Code · Python 3.9+ · `openpyxl` · `python-docx` (`python -m pip install openpyxl python-docx` · python-docx 는 워드 리포트용 · 없으면 워드만 건너뜀)
- 오프라인 교육장: 이 폴더를 USB · 공유 폴더로 받아 같은 명령으로 설치
- 플러그인은 GitHub 에 따로 올리지 않는다 (2026-11-15). 교육생 각자의 작업 폴더를 비공개 저장소 `hr-agent` 로 올리고 (Day 1 첫 푸시 · 매일 저장), Day 3 가져가기 때 그 안에 이 폴더 사본을 넣는다 (`take_home.py copy-plugin`)

## 체크포인트 (사람이 판단하는 자리)

| CP | 자리 | 기본 승인자 |
|---|---|---|
| CP1 열 대응 확인 | ① 뒤 · 숫자 확정 전 | 인사기획 실무 담당 |
| CP2 동인 선정 | ② 안 · 되돌리기 어려운 결정 | 인사기획팀장 |
| CP3 공급 가정 | ③ 앞 · 숫자 확정 전 | 인사기획팀장 |
| CP4 Gap 대안 승인 | ④ 뒤 · 되돌리기 어려운 결정 | 인사기획팀장 + R 행 소관 본부장 (나머지 행은 Y · G 계획 승인으로 이유 칸에 기록) |
| CP5 리포트 공유 | 리포트 뒤 · 외부 공유 전 | CHRO |

- 승인자는 기본값이다. 자사 승인자는 `config.json` approvers 로 바꾼다 (예 `{"CP2": "인사팀장"}` · 자사 예 · 가설)
- 답은 확정 · 추가 확인 · 보류 · 이관 넷 중 하나. 승인은 대화로 답하고 리드가 기록한다. 다음 단계 스크립트가 앞 CP 승인 기록을 확인하므로 건너뛸 수 없다 (`require_cp` · CP1~CP5 만)
- 데이터 이상은 「예외」, 검증 미해결은 「관문」으로 멈춘다 (같은 4요소 · 결정로그). 관문을 고치지 않고 가기로 하면 「관문 인정」 (결정로그에 이유)
- 검증 행 상태: 통과 · 미해결 · 해결 · 미확인 · 인정 (결정로그 #n) (인정 = 관문 인정 답 · `verify.py accept` 가 적음 · 미해결로 세지 않음 · 범위 밖 거절 행동 테스트는 스크립트가 「미확인」으로 적고 검증 담당이 실제로 물어본 뒤 고침)
- 자사 버전에서 CP 5곳은 잠금 (승인자 · 기준 변경 · CP 추가만 허용)

## 자사 버전에서 지키는 것

기본 골격 그대로 · 데이터 연결 · **변형 한 칸** (동인 · 계획 단위 · Gap 우선순위 · 리포트 양식 중 하나) · 잠금 검사 · K-Co. 회귀 테스트 · 변경 이력. 자세한 것은 `skills/pwc-hr-harness/references/customization-guide.md`.

## 기본 팀이 기본으로 막는 것 · 막지 않는 것

| 구분 | 무엇 | 어떻게 |
|---|---|---|
| 막음 (스크립트) | 앞 CP 승인 없이 다음 단계 계산 | 단계 스크립트의 `require_cp` (CP1~CP5 만 · 자사 CP 추가는 리드 Skill 규칙으로만 멈춤) |
| 막음 (스크립트) | 빈칸을 0 으로 읽기 · 기준일이 다른 시트 합치기 · 소계 · 합계를 데이터로 읽기 · 감원 단독 대안 | 「예외」 멈춤 · `step4.py check` |
| 막음 (스크립트) | 검증 미해결이 남은 채 진행 | `verify.py` 「관문」 (종료 코드 3) |
| 규칙만 (지시문) | `data/<회사>/` 밖 파일 읽기 · 인터넷 검색 · 개인 명단 · 개인 평가 · 리포트 반출 (CP5 전) | CLAUDE.md 「업무 범위 · 금지」 · 각 Skill 금지 · 검증 「범위 밖 거절」 행동 테스트로 확인 |
| 막지 않음 | 외부 전송 (Bash 로 메일 · 업로드 · 복사) · 담당이 결과 파일을 손으로 고치기 | 훅 없음 · 담당 도구에 Bash · Write · Edit 가 있음. 사내 이전 때 훅 · 권한 설정 · 사내 정책으로 막는다 (뷰어 「하네스」 › 훅 · 권한 후보 카드로 요청 · 작업 폴더 `.claude/settings.json`) |
| 막지 않음 | 개인정보 열 감지 · CP 순서 변경 | 감지 기능 없음 (잠금 검사는 CP 삭제 · 문장 삭제만 잡음) |

## 가상 데이터 (자사 파일이 없을 때)

- 자사 데이터 항목과 대략의 규모만 알면 `/hr-customize` 데이터 연결 단계에서 가상 데이터를 만든다: `양식/가상데이터_설정_예.json` 을 `data/<폴더>/가상데이터_설정.json` 으로 복사해 채우고 `python -X utf8 .claude/hr-lib/virtual_data.py --co <폴더>`
- K-Co. 분포를 규모 · RPU 에 맞춰 옮기는 결정적 스크립트다 (같은 설정 = 같은 내용 · 개인 식별 열 없음 · 기존 파일은 덮지 않음 · `추가_*` 자료는 함께 둘 수 있음)
- 선택 칸 (비우면 K-Co. 값): 성장 시나리오 · 사업 이벤트 (신설 조직) · 동인 (이름 · 단위 · 계획) · 추가 동인 · AI 범위 · 인건비 인상률. Day 3 에는 「가상 데이터로 회사 폴더 만들어 줘 … 회사 이름 X, 폴더 Y」 한 문장을 리드가 `data/<폴더>/가상데이터_설정.json` 으로 옮긴다 (선택 도우미 `양식/자사조건카드.md` 를 채워 왔으면 그것을 옮기고 빈 칸만 묻는다) (K-Co. 예시 값: `양식/K-co_조건예시.json`)
- 결과에는 「가상 데이터로 만든 결과 · 실제 판단에 쓰지 않음」이 붙는다 (표시 파일 · 리포트 첫 줄 · 뷰어 배너 · 표시가 빠지면 검증 관문). 자세한 것은 `customization-guide.md` 2-1

## 데이터 · 보안

- 에이전트는 `data/<회사>/` 폴더만 읽는다. 개인 단위 명단 · 평가를 만들지 않고, 감원 대안을 단독으로 내지 않는다
- 뷰어는 로컬 파일 하나다 (인터넷 불필요). 리포트 숫자가 들어 있으므로 CP5 승인 전에는 밖으로 보내지 않는다
- 뷰어는 만들 때마다 기본 브라우저로 열린다. 열린 탭은 새 판을 스스로 다시 읽고, 새 탭이 열리면 지난 탭은 스스로 닫힌다. 멈춘 CP · 예외 · 관문은 첫 화면 「개요」의 「지금 정할 것」에 4요소로 뜨고, 근거 파일을 누르면 「문서」 화면에서 그 절이 열린다. 화면은 왼쪽 메뉴 (개요 · 진행 · CP · 대시보드 · 산출물 · 문서 · 리포트 · 검증 · 회귀 · 하네스 · 변경점)로 고른다. 시험 · 녹화처럼 자동으로 돌릴 때는 `HR_VIEWER_OPEN=0`
