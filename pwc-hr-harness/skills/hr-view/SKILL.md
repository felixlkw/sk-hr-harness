# hr-view · HTML 뷰어

## 실행 (작업 폴더에서)

```
python -X utf8 .claude/hr-lib/render.py            # hr-viewer.html 만들기 + 기본 브라우저로 열기
python -X utf8 .claude/hr-lib/render.py --no-open  # 만들기만
```
- **만들 때마다 브라우저로 연다** (Windows · Mac). 탭이 쌓이지 않게 두 장치가 있다: ① 이미 열린 뷰어 탭은 2초마다 `.claude/hr-lib/_viewer_stamp.js` 를 읽어 새 판이면 스스로 다시 읽는다 (보던 탭 · 문서 · 스크롤 자리 유지) ② 새 탭이 열리면 같은 파일을 연 지난 탭은 스스로 닫힌다 (Chrome · Edge. 닫지 못하는 브라우저는 「이 탭은 닫아도 됩니다」 띠만 보임)
- 자동으로 돌릴 때 (시험 · 동영상 시연 녹화 `claude -p`)는 환경 변수 `HR_VIEWER_OPEN=0` 이면 열지 않는다. `CI` 가 있어도 열지 않는다. 결과 JSON 의 `opened` · `open_off` 로 확인
- Mac: `python3` · 작업 폴더에 `.claude/hr-lib/render.py` 가 없으면 `/hr-init` 먼저
- 인터넷 · 계정 없이 열리는 파일 하나. 결과 파일을 읽기만 하고 고치지 않는다
- 메일 · 메신저로 보내는 것은 리포트 공유 (CP5) 승인 뒤에만 한다 (뷰어에 리포트 숫자가 들어 있음)

## 화면 (왼쪽 메뉴)

| 메뉴 | 보이는 것 | 언제 보라고 안내하나 |
|---|---|---|
| 개요 (첫 화면) | **「지금 정할 것」 카드** (정할 것 · 근거 파일 · 선택지 · 답 형식) · 숫자 타일 (결정 수요 사람 · 디지털 · 공급 기본 · 상승 · Gap · 현원 · 값이 없으면 「아직 없음」) · 단계 진행 (① ~ ④ · 리포트 · CP1~CP5) · 담당이 짚어 둔 것 · 검증 요약 | 멈췄을 때마다 · 단계 끝 |
| 진행 · CP | 「지금 정할 것」 · CP1~CP5 상태 (승인 · 대기 · 자료 없음 · 앞 CP 먼저) · CP 마다 근거 파일 링크와 볼 절 (확인 필요 · 사람 답 칸 · 승인 칸) · 담당이 짚어 둔 것 (파일 안 「확인 필요」 · 「사람에게 물을 것」 절) · 결정로그 · 예외 수 | 멈췄을 때 |
| 대시보드 | 숫자 타일 · RPU별 Gap 막대 · B · C · 결정 수요 비교 (마우스를 올리면 값 · 표로 보기) | ② · ④ 뒤 |
| 산출물 | 단계별 md · xlsx 전체 (펼쳐 보기 · HR Index 는 저장 자리수 그대로) · 기록 · 멈춤 (결정로그 · 검증로그 · `_멈춤.md`) | 숫자 근거를 볼 때 |
| 문서 | `outputs/<회사>/` 의 .md 전부를 읽기 좋은 화면으로 (표 · 제목 · 목록 · 굵게 · 코드 · 링크) · 파일 목록 · 목차 · 「확인 필요」 같은 절로 바로 가기 | CP 근거를 읽을 때 |
| 리포트 | 리포트 7섹션 | 리포트 뒤 · CP5 |
| 검증 | 검증로그 · 미해결 수 · 미확인 수 (행동 테스트 대기) | 검증 뒤 |
| 회귀 | K-Co. 회귀 테스트 결과 (`_회귀테스트.md`) | regress 뒤 |
| 하네스 | 팀 구성도 · CLAUDE.md · 에이전트 5 · Skill 7 (스크립트) · 훅 · MCP · 권한 카드 (절마다 🔒 잠금 · ✏️ 변형 메뉴 · 본문 펼쳐 보기 · 「원본 열기」 = VS Code) · 「수정」 = 브라우저 안 초안 · 차이 · 잠금 경고 · 「Claude 에게 맡길 문장 복사」 · 요청 바구니 · 훅 · MCP · 권한이 없으면 후보 카드 | 설치 직후 · 하네스를 고치고 싶을 때 |
| 변경점 | 기본 대비 변경점 (`customize.py lock` · `diff` 와 같은 셈) · CLAUDE.md 변경 이력 | 자사 버전 변형 뒤 |

- 위쪽 바: 지금 화면 이름 · 상태 알약 (「CP2 대기」 · 「관문 · 검증」 · 「멈춘 곳 없음」) · 회사 단추 (K-co · E-co · 자사 …) · 생성 시각 · 밝게 · 어둡게 단추. Day 3 에서 회사 단추로 K-Co. ↔ E-Co. ↔ 내 회사를 비교한다
- 개요 밖 화면에서는 「지금 정할 것」이 위쪽 띠로 붙어 다닌다 (「4요소 보기」 → 개요). 가상 데이터 배너도 모든 화면 위쪽
- 휴대폰 폭에서는 왼쪽 메뉴가 접히고 ≡ 단추로 연다. 인쇄하면 모든 화면이 차례로 찍힌다
- 양식 그대로인 파일 (사람 칸 · 스크립트 칸이 모두 빔)은 「자료 없음」으로 본다. 앞 CP 가 승인 전이면 뒤 CP 는 「대기」가 아니라 「앞 CP 먼저」로 보인다
- 결정로그에 「데이터 반영」 확정 행이 있으면, 그 행이 다시 받을 CP 로 적은 CP (또는 승인 칸 답이 「추가 확인 (데이터 반영 #n)」인 CP)는 다시 승인한 기록이 생길 때까지 진행 막대 · CP 카드 · 위쪽 알약에 「재승인 필요 · 데이터 반영 #n」으로 보인다. 멈춤 파일이 가리키는 CP 가 이미 승인됐으면 (예: CP5 확정 뒤 남은 파일) 그 멈춤은 「지금 정할 것」에 띄우지 않는다
- 「지금 정할 것」을 고르는 순서: 지금 멈춘 곳 (`_멈춤.md` · CP · 예외 · 관문) → 관문 대기 (검증로그 미해결 · 미확인) → 승인 대기 CP. 근거 파일 이름을 누르면 「문서」 화면에서 그 파일의 해당 절 (「## 승인」 · 「7. 확인 필요」 등)이 열린다
- 「하네스」 화면은 파일을 쓰지 않는다. 초안 · 요청 바구니는 그 브라우저에만 남고, 복사한 「/hr-customize 하네스 수정 요청」 문장을 대화창에 붙여 넣으면 Claude 가 적용한다 (잠금 검사 · K-Co. 회귀 · 변경 이력 · 뷰어 갱신). 고치는 창이 열려 있으면 새 판이 와도 다시 읽지 않고 창을 닫을 때 읽는다
- 바로 여는 주소: `hr-viewer.html#tab=dash&co=K-co` (tab = home · flow · dash · out · doc · report · verify · regress · harness · changes) · 한 절: `hr-viewer.html#co=K-co&doc=②_수요파라미터.md&sec=7. 확인 필요`

## 리드가 알릴 때

「뷰어를 다시 열었습니다. 첫 화면 「지금 정할 것」에 CP2 가 떠 있고, 근거 `②_수요파라미터.md` 를 누르면 7. 확인 필요 절이 열립니다」처럼 **볼 자리와 볼 것**을 한 문장으로 알린다.
