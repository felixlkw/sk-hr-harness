# 자사 인력계획 Agent 기획안

> **참고 · Day 3 수업에서 쓰지 않음.** 과정 뒤 회사에서 자사 버전을 처음부터 설계할 때 생각을 정리하는 틀이다. Day 3 은 교안의 붙여 넣을 문장으로 진행한다.

- 쓰는 때: 자사 버전 설계서를 쓸 때 (선택). 7칸을 먼저 잡고 `양식/자사버전_설계서.md` 0~5절로 옮김
- 한 장에 7칸을 채움. 칸마다 「옮겨 올 곳」에 적힌 자료에서 먼저 옮기고, 비는 곳만 새로 씀

- K-Co. 로 채운 모습은 Day 1 · 2 결과 (`outputs/K-co/`) 와 기본 팀 `CLAUDE.md` · `.claude/` 를 보면 된다
