# 인력계획 에이전트 PRD

- 쓰는 때: Day 1 ① 사업전략 · 요구사항 분석 (교안 120~123p)
- PRD는 K-Co.와 공통으로 하나만 쓰고, 끝의 「자사 차이」 칸에 자사 RPU와 동인 후보, 계획 단위만 적음
- 모르는 칸은 「확인 필요」로 남기고 에이전트가 묻게 함
- 견본은 교안 121p의 K-Co. PRD

## PRD 6칸

| 번호 | 칸 | 무엇을 적나 | 작성 | 확인 |
|---|---|---|---|---|
| 1 | 목적 | 골든서클 「왜」 하나를 고름 (인건비 효율 · 인력 증감 대응 · 실행력 강화) |   | 한 줄로 말할 수 있는가 |
| 2 | 사용자 | 누가 돌리고 · 확인하고 · 승인하는가 (직책) |   | 체크포인트마다 답할 사람이 있는가 |
| 3 | 입력 데이터 | 어떤 파일을 읽는가 |   | 파일마다 데이터 사전이 있는가 |
| 4 | 단계 | ① 요건 → ② 수요 → ③ 공급 → ④ Gap |   | 단계마다 Skill이 하나씩인가 |
| 5 | 체크포인트 | CP 5곳 (CP1 열 대응 확인 · CP2 동인 선정 · CP3 공급 가정 · CP4 Gap 대안 승인 · CP5 리포트 공유)마다 무엇을 묻는가 (멈춤 문구: 무엇을 정했나 · 근거 파일 · 선택지 2~3 · 답 형식) |   | 되돌리기 어려운 결정 앞인가 |
| 6 | 출력 | 어떤 파일을 어디에 내는가 |   | 파일 이름이 정해졌는가 |

## 자사 차이 3칸

| 칸 | 작성 | 확인 |
|---|---|---|
| 자사 RPU |   | 같은 동인을 쓰는 일의 묶음으로 적었는가 |
| 동인 후보 |   | RPU마다 2~3개, 2027 목표가 있는 것 위주인가 |
| 계획 단위 |   | 판정 흐름 (교안 116p)과 이유 한 줄이 있는가 |

- 목적, 단계, 체크포인트, 출력은 K-Co.와 같게 둠 (Day 2에 K-Co.와 자사를 같은 Skill로 돌리기 때문)
- 다음 순서: AI 기초 시간에 `/hr-init` 으로 설치한 기본 팀에 ① 을 맡기고 (교안 122p 명령), 생긴 파일을 PRD와 대조한 뒤 123p 질문 3개로 검산함
