# 추가 데이터 정의서 (선택 도우미)

> 참고: Day 3 은 회사 적용 도우미 (`/hr-customize` · 질문 7) 와 리드 (`wfp-lead` 3-0) 가 묻는 말에 답하며 자료를 넣는다. 넣을 자료가 여럿이라 먼저 정리하고 싶을 때만 쓴다. 0.11.0 부터 도우미 · 리드는 갈래를 「근거 인용 · 입력 교체 · 계산 변경」 으로 부른다 (아래 ① 동인 = 입력 교체의 한 경우 · ② 판단 근거 = 근거 인용 · ③ 계산 = 계산 변경)
>
> 기본 6종 밖에 쓰고 싶은 데이터를 한 행씩 적고, 아래 판정 순서로 3갈래 중 하나를 고른다. 실데이터 · 개인 단위 자료는 적지 않는다 (가상 · 집계 단위).

## 2. 갈래 판정 (위에서부터 처음 「예」인 곳)

| 질문 | 예이면 | 하는 일 | 코드 |
|---|---|---|---|
| RPU 마다 해마다 같은 정의로 모이고, 인원과 함께 움직이며, 계획 연도 목표 값이 있는가 | **① 동인으로** | `가상데이터_설정.json` 「추가 동인」 (또는 실데이터면 파일 6 조직별 인력동인 시계열에 행 추가) → CP2 후보 | 필요 없음 |
| 숫자 계산이 아니라 판단 칸 (Pivotal 근거 · 4B 대안 · 재배치 경로)에 쓰는 자료인가 | **② 판단 근거로** | `data/<자사>/추가_<이름>.xlsx` 로 넣음 → `step1.py scan` 이 ①_열대응표 「추가 자료」로 보고 → 담당이 「회사 기준 · 파일명」으로 인용 · Skill 판단 규칙 한 줄 개정 (선택 · `/hr-customize`) | 필요 없음 |
| 업무량 · 공급 · Gap 숫자 자체를 바꿔야 하는가 (예: 초과근무로 업무량 보정 · 외주 인원을 Borrow 가능 인원으로) | **③ 계산으로 (심화)** | 새 계산 스크립트 + Skill · K-Co. 회귀 시험 필수 · 개정 · 회귀가 따름 (선택 · 심화) | 필요 |

- ② 갈래 파일은 이름을 꼭 `추가_` 로 시작한다 (기본 표로 잘못 잡히지 않게 scan 이 막음 · 가상 데이터를 다시 만들어도 지워지지 않음). 첫 줄 안내문에 「가상」을 적어 두면 가져가기 점검이 가상 자료로 본다
- 개인 식별 열 (성명 · 사번 · 생년월일 · 연락처)은 어느 갈래에도 넣지 않는다

## 4. Claude 에게 할 말

- ① 「<RPU 코드> 에 <이름> (<단위>, 기준 값 <값>, 계획 증가율 <n>%) 을 추가 동인으로 넣어 가상 데이터 다시 만들어 줘」
- ② 「data/<자사>/추가_<이름>.xlsx 넣었어. 열 대응표 다시 만들고 추가 자료로 보이는지 확인해 줘」 → (선택) 「/hr-customize ④ Skill 에 이 자료를 대안 근거로 인용하는 규칙 한 줄 넣어 줘」
- ③ 「<무엇> 을 계산에 넣고 싶어. 개정 요청서로 정리해 줘」 (강사와 함께)
