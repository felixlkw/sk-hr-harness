# wfp-report · 리포트 7섹션

1. `python -X utf8 .claude/skills/wfp-report/scripts/report.py build --co <회사>` → `리포트_<회사>_<연도>.md` 의 숫자 칸 (auto 블록)이 결과 파일에서 채워진다
2. 리드가 「1. 요약 · 핵심 메시지」를 10줄 이내로 쓴다
   - 첫 문장은 PRD · 기획안의 목적 「왜」 (인건비 효율 · 인력 증감 대응 · 실행력 강화 중 하나)에 맞춘다
   - 문장마다 출처 (결과 파일 이름). 숫자는 결과 파일 숫자를 옮기기만 하고 다시 계산하지 않는다
   - 결론을 정해 놓고 숫자를 맞추지 않는다. 가정 · 한계 (표본 5개 회귀 · AI 처리량 계수 가정값)를 한 줄 밝힌다
3. `wfp-verifier` 로 `--stage report` 검증 → 미해결 0 → **CP5 리포트 공유**에서 멈춤 → 승인 뒤에만 폴더 밖으로 공유
   - 사람이 「확정」하면 리드가 승인 칸 · 결정로그를 적고 `report.py confirm --co <회사>` 를 한 번 돌린다 (CP5 승인 확인 · 지난 CP5 멈춤 파일을 닫음 · 리포트는 다시 쓰지 않음)
   - 숫자가 바뀐 뒤 `build` 를 다시 돌리면 CP5 답 칸이 비워져 다시 CP5 에서 멈춘다 (지난 답은 결정로그에 남음)
4. 뷰어를 다시 만든다: `python -X utf8 .claude/hr-lib/render.py` (브라우저로 열림) → 「리포트」 화면 · CP5 멈춤은 첫 화면 「지금 정할 것」에 뜬다

## 자사 버전에서 바꿀 수 있는 것

- 리포트 목차를 자사 보고 형식으로 바꿀 수 있다 (변형 메뉴 「리포트 양식 교체」). 단 7섹션의 내용 (가정 · 검증 로그 포함)은 빠지지 않게 하고, CP5 는 지우거나 우회할 수 없다
