`$ARGUMENTS` 를 보고 아래 갈래 가운데 처음 맞는 것 하나를 따른다. 맨 앞에 `/hr-customize` · `/pwc-hr-harness:hr-customize` 가 한 번 더 붙어 있으면 떼고 본다.

0. **인자 없음 · 도우미:** `$ARGUMENTS` 가 비었거나 「회사 적용 도우미」 「새 회사로 하네스 맞춰 줘」 「도우미 이어서」 「우리 회사 PRD 만들어 줘」 「우리 회사 브리프 만들어 줘」 「우리 회사 진단해 줘」 「결과 읽어 줘」 「설계서 다시 만들어 줘」 같은 말이면 `pwc-hr-harness` 스킬 **모드 F (회사 적용 도우미)** 를 따른다: 대본 `${CLAUDE_PLUGIN_ROOT}/skills/pwc-hr-harness/references/adapt-interview.md` 를 **먼저 Read** (다른 곳을 찾지 않는다 · 다른 판 플러그인 캐시 금지) · 처음에 `adapt.py status` (회사 폴더를 모르면 그것만 묻는다) · 한 번에 한 질문.
1. **하네스 수정 요청:** 「하네스 수정 요청」으로 시작하면 (뷰어 「하네스」 화면에서 복사한 문장 · 앞의 `/hr-customize` 가 빠진 채 붙여 넣은 것도 같음) `pwc-hr-harness` 스킬 **모드 C 의 「뷰어에서 온 하네스 수정 요청」** 순서를 따른다: 작업 폴더 사본에 diff 적용 → 잠금 검사 → K-Co. 회귀 → CLAUDE.md 변경 이력 한 행 → 뷰어 다시 만들기. 「잠금 칸 변경: 있음」이거나 잠긴 줄을 건드리면 적용 전에 멈추고 4요소로 묻는다.
2. **담당 · 스킬 · 리드 줄 더하기:** 「담당 (하나) 더해 줘」 「스킬 더해 줘」 「팀에 담당 하나와 스킬 둘을 더해 줘」 「데이터 반영 담당 만들어 줘」 「wfp-lead 에 한 줄 더해 줘」 「결정로그 행 종류에 … 더해 줘」처럼 팀에 담당 · 스킬을 더하거나 리드 · 결정로그 양식에 줄을 더하는 요청이면 `pwc-hr-harness` 스킬 **모드 C 의 「팀에 담당 · 스킬 더하기」** 순서를 따른다 (모드 B 를 처음부터 하지 않는다 · 「변형 메뉴 밖」으로 처리하지 않는다 · 행동 점검 3종까지 한다). 데이터 반영 담당이면 그 절의 「예시 틀 · 데이터 반영 담당」 네 가지를 intake 스킬에 넣는다. 리드 · 결정로그 줄만 더하는 요청이면 그 절의 3 (리드 연결) · 새 기록 종류 규칙부터 4 (잠금 · 회귀) · 6 (변경 이력) · 7 (뷰어) 로 간다.
3. **가상 회사 폴더 만들기:** 「가상 데이터로 회사 폴더 만들어 줘 … 회사 이름 X (, 폴더 Y)」처럼 가상 회사 폴더를 만드는 요청이면 모드 B 의 **B2 갈래 「가상 데이터 만들기」** 로 바로 간다 (B1 설계서 읽기는 건너뜀). 폴더 이름 = 문장에 적힌 폴더 (없으면 회사 이름에서 괄호 · 공백을 뺀 이름을 제안하고 확인). `data/<폴더>/가상데이터_설정.json` 이 이미 있으면 그 파일을 쓰고, 문장 내용과 다른 칸만 「설정 파일 값과 다름」으로 보여 확인한다. 없으면 문장 내용을 그 파일로 옮기고 (칸 뜻은 `양식/가상데이터_설정_예.json`) 문장에 없는 칸은 비워 둔다 (K-Co. 값). 도구는 늘 `--co <폴더>` 로 돌린다: `virtual_data.py --co <폴더> --dry-run` → 확인 → `virtual_data.py --co <폴더>` → `step1.py scan --co <폴더>` → CP1.
4. **규칙 한 칸 바꾸기:** 「(무엇을) 바꿔 줘. 근거는 …」처럼 이미 돌린 하네스의 규칙 · 승인자 · 동인 한 칸을 바꾸는 요청이면 모드 B 의 B4 (변형 한 칸) 부터 B5 변경 이력 → B6 잠금 검사 → B7 K-Co. 회귀 순서로 간다 (B0 기준 스냅샷이 없으면 「K-Co. 결과를 기준으로 남길까」를 먼저 묻는다).
5. **그 밖:** 회사를 새로 맞추는 요청이면 모드 F (도우미) · 설계서를 채워 와서 그대로 적용해 달라는 요청이면 `pwc-hr-harness` 스킬의 **모드 B (자사 버전 업데이트)** 를 처음부터 따른다. 기획안 · 설계서 파일이 채워져 있으면 (`양식/기획안_양식.md` · `양식/자사버전_설계서.md` · 선택) 먼저 읽는다. 자사 파일이 없으면 B2 에서 「가상 데이터 만들기」 갈래로 간다: 회사 특성 정리 (`양식/자사조건카드.md` · 선택)가 채워져 있으면 그것을 `data/<폴더>/가상데이터_설정.json` 으로 옮기고 빈 칸만 묻는다 (칸 뜻은 `양식/가상데이터_설정_예.json`).
